# Lexio

Приложение для заучивания английских слов на слух. Под Windows.

Карточка здесь привязана не к слову, а к **отдельному его смыслу**: у `run`
смыслов десяток, и знать один — не значит узнать слово в другом. Поэтому
единица заучивания — пара «слово + смысл», и у каждой пары своё расписание
повторов.

Внутри:

|---|---|
| карточек | 29 831 |
| слов | 20 608 |

## Лады

Каждый лад тренирует своё, и в каждом работает один канал, а не все сразу.

- **Слушаю** — звук → значение. Главный.
- **Различия** — что разводит `forbid` и `prohibit`, `say` и `tell`. Спрашивается выбор, а не перевод.
- **Определение** — смысл → слово. Русского нет вовсе: единственный лад, где вы создаёте слово, а не узнаёте.
- **Смотрю** — картинка → слово.
- **Пишу** — звук → написать слово.
- **Говорю** — произнести и получить разбор по звукам. Требует доустановки, см. инструкцию внутри архива.

## Скачать

Готовая сборка лежит в раздел [Releases](../../releases/latest) — файл `Lexio.7z`, около 1,4 ГБ.

**Архив закрыт паролем.** Пароль спросите у владельца репозитория; без него архив
не откроется и даже список файлов внутри не покажется.

Распаковать нужно любым из: [7-Zip](https://www.7-zip.org),
[WinRAR](https://www.win-rar.com), [PeaZip](https://peazip.github.io) —
встроенный проводник Windows формат `.7z` не открывает.

Внутри архива лежит `КАК УСТАНОВИТЬ.txt` — там всё по шагам, включая то,
что Windows покажет предупреждение SmartScreen (программа не подписана) и
что с этим делать.

## Требования

Windows 10 или 11, 64 бита. Полтора гигабайта на диске. Ничего больше
ставить не нужно — питон и библиотеки уже внутри.

Единственное исключение — лад «Говорю»: разбор речи весит слишком много,
чтобы класть его в архив, и ставится отдельно одной командой. Как
именно — написано в инструкции внутри.

## Данные

Все данные — обычные файлы JSON рядом с программой, открываются
блокнотом. Приложение ничего не держит в облаке, работает без сети и
не имеет единственной копии чего бы то ни было: папку `Данные` можно
скопировать целиком и это будет полный перенос.

В раздаваемой сборке расписание повторов сброшено — все карточки новые.
